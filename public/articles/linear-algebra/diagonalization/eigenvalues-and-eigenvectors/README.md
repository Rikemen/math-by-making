# 固有値と固有ベクトルの幾何学的意味

\( A\vec{v} = \lambda\vec{v} \) を満たす固有値 \( \lambda \) と固有ベクトル \( \vec{v} \) の数学的定義を学び、正方行列がベクトルを「回転させずスカラー倍する方向」であることを手計算とインタラクティブな可視化で確かめる教材です。

## 学習内容

- 固有値と固有ベクトルの数学的定義式 \( A\vec{v} = \lambda\vec{v} \) とゼロベクトル除外の理由
- 特性方程式 \( \det(A - \lambda I) = 0 \) による固有値・固有ベクトルの導出と検算
- 固有空間（不変直線）と固有値による幾何学的挙動の分類（伸長・縮小・反転・退化）
- 固有ベクトル基底による任意ベクトルの独立な伸縮への分解
- JavaScriptによる外積を用いた平行・固有ベクトル判定アルゴリズム
- p5.jsによるインタラクティブなベクトル変換と単位円写像（楕円変形）の幾何学的可視化
