線形代数

線形写像 (Linear Mapping)

定義を読み、行列による実装と動くグリッドで線形写像を確かめます。

この教材の学習目標

  • 線形写像が保つ加法とスカラー倍を説明できる。
  • 線形写像を行列の積として実装できる。
  • 像・核・次元定理を可視化と結び付けて理解できる。

1. 写像とは何か？

「写像 (Mapping)」とは、ある集合の各要素に対して、別の集合の要素を「ただ一つ」対応させる規則のことです。関数 (Function) とほぼ同じ意味ですが、線形代数では「ベクトル空間からベクトル空間への対応関係」を強調して「写像」と呼ぶことが多いです。

2. 線形写像とは何か？

写像の中でも、ベクトル空間の持つ重要な構造である「足し算（和）」と「定数倍（スカラー倍）」という性質を壊さずに保つ写像を、線形写像 (Linear Mapping) または 線形変換 (Linear Transformation) と呼びます。

💡 線形写像の定義

ベクトル空間 \(V\) からベクトル空間 \(W\) への写像 \(f: V \to W\) が以下の2条件を満たすとき、\(f\) は線形写像であるといいます。

  • 加法性: 任意の \(\vec{x}, \vec{y} \in V\) に対して、\(f(\vec{x} + \vec{y}) = f(\vec{x}) + f(\vec{y})\)
  • 斉次性: 任意の \(\vec{x} \in V\) とスカラー \(c\) に対して、\(f(c\vec{x}) = c f(\vec{x})\)
🤔 なぜ「線形写像」を考えるのか？（モチベーション）
現実世界の問題は複雑で非線形な現象に溢れていますが、狭い範囲に限定すれば線形に近似できることが多くあります（微分の考え方）。
線形写像の最大の強みは、「基底ベクトルの行き先さえ決まれば、空間全体の全てのベクトルの行き先が完全に決定される」という強力な性質を持っていることです。これにより、どれほど複雑な空間の変換であっても、有限個の数の表である「行列」を使ってシンプルかつ統一的に計算・分析できるようになります。

2.1 具体例

直感的に言えば、原点を固定したまま空間を「回転」「拡大縮小」「ひしゃげさせる（せん断）」「ペチャンコにする（射影）」ような変換が線形写像です。

  • 線形写像の例: 回転、原点を中心とした拡大・縮小、ある軸への正射影など。これらは直線を直線のまま保ち、原点は必ず原点に移ります。
  • 線形写像ではない例:
    • 平行移動: \(\vec{x} \mapsto \vec{x} + \vec{a} \ (\vec{a} \neq \vec{0})\)。これは原点 \(\vec{0}\) を \(\vec{a}\) に移してしまうため、\(f(\vec{0}) = \vec{0}\) という線形写像の絶対条件を満たしません。（アフィン変換と呼ばれます）
    • 二乗する変換: \(\vec{x} \mapsto \vec{x}^2\)。\(f(2\vec{x}) = 4f(\vec{x})\) となり、定数倍が保存されません（直線が曲線に曲がってしまいます）。

3. 線形写像と行列

数ベクトル空間における線形写像は、すべて行列の掛け算で表すことができます。

\[ f(\vec{x}) = A \vec{x} \]

この行列 \(A\) を構成するのは非常に簡単です。標準基底 \(\vec{e}_1, \vec{e}_2, \dots\) が写像 \(f\) によってどこに移るかを調べ、その結果を「列ベクトル」として順番に並べるだけで、その写像を表す行列が完成します。

4. 像 (Image) と 核 (Kernel)

線形写像 \(f\) を深く理解するために、2つの重要な集合（部分空間）を考えます。

💡 像 (Image)

写像 \(f\) によって「入力空間のベクトル全体が移った先（出力の集合）」のことです。\(\text{Im}(f)\) と書きます。
行列 \(A\) による変換の場合、行列の各列ベクトルの一次結合で作られる空間（列空間）と一致します。この 像の次元 を 階数 (Rank) と呼び、行列が持つ「情報量の広がり」を表します。

💡 核 (Kernel)

写像 \(f\) によって「ゼロベクトル (\(\vec{0}\)) に潰されてしまう入力ベクトルの集合」のことです。\(\text{Ker}(f)\) と書きます。
これは連立一次方程式 \(A\vec{x} = \vec{0}\) の解の集合（解空間）と同じものです。核が \(\{\vec{0}\}\) だけなら、違うベクトルは違う場所に写る（単射である）ことが保証されます。

5. 次元定理 (Rank-Nullity Theorem)

線形写像において、入力空間の次元と、像の次元、核の次元の間には、非常に美しく強力な関係が成り立ちます。

\[ \dim(V) = \dim(\text{Im} f) + \dim(\text{Ker} f) \]

入力空間の次元 \(\dim(V)\) は、写像によって「生き残る次元（像の次元, Rank）」と「潰されて消えてしまう次元（核の次元, Nullity）」に綺麗に分かれます。これは線形代数における情報量の保存則とも言える重要な定理です。

1. 線形写像の実装

理論編で学んだ「線形写像」を、プログラム上の Matrix クラスでどのように実現するかを解説します。

1.1 ベクトルへの線形写像の適用

線形写像は行列の積として表せるため、ベクトル \( \vec{x} \) に変換行列 \( A \) を左から掛けることで実装できます。 

// 2Dベクトル x = (2, 1)
let x = new Matrix(2, 1);
x.set([[2], [1]]);

// 90度回転の行列 A
let A = new Matrix(2, 2);
A.set([[0, -1], [1, 0]]);

// 写像の適用：A * x
let result = Matrix.multiplyMatrices(A, x);

1.2 線形写像の合成

2つの線形写像 \( f \)（行列 \( A \)）と \( g \)（行列 \( B \)）を連続して行う合成写像 \( g \circ f \) は、行列の積 \( BA \) を計算するだけで表現できます。 

// 2倍に拡大する行列 B
let B = new Matrix(2, 2);
B.set([[2, 0], [0, 2]]);

// 「回転してから拡大する」合成写像の行列 BA
let BA = Matrix.multiplyMatrices(B, A);

1.3 像と核の計算

行列の像 (Image) や核 (Kernel) をプログラムで求めるには、ガウス・ジョルダン消去法による行列の簡約化（階段行列化）を利用します。

  • 像の基底: 行列 \(A\) を簡約化した際に、主成分（ピボット）が存在する列を見つけます。その列番号に対応する「元の行列 \(A\) の列ベクトル」が像の基底になります。
  • 核の基底: 簡約化された行列から、\(A\vec{x} = \vec{0}\) の一般解をパラメータを用いて解くことで、核の基底ベクトルを抽出します。
