# Math by Making

## Project Overview
Math by Makingは「創って学ぶ」をコンセプトにした数学学習Webアプリケーション。

数学の概念をプログラミングで実装することで、手触り感や直感的な理解をできるようにする。

## ユーザーの学習プロセス
1. 数学の概念を資料ベースで読んで学べる（スマホ最適化）
2. 資料に対応したYoutube動画を撮影しておき、記事内やYoutubeから閲覧できる
3. 記事の中に、数学概念を実装するコードがあり、解説される
4. 一部が問題となっており、progateのようにブロック式や選択問題でユーザーも数学を創る体験ができる
5. 記事ごとにコードはGithubに公開されており、自分でDLして利用することも可能

## 記事の作成プロセス
1. 記事ごとにフォルダを作成し、そこにindex.html, sketch.js, Matrix.jsなどの必要なファイルがある
2. 記事ごとにに概念を追加していくので、記事ごとに多少冗長でもフォルダは作成する
3. 記事の執筆はスマホからAIを通して行い、Deployをしながら内容確認して創っていく

## 技術構成
1. html, css, javascript (p5.js etc.)
2. vue.js, firebase

## 仕様
1. ユーザーアカウントなどは最初は不要で、気軽にアクセスして学習できるようにする
