Math by Making 開発計画

「創って学ぶ」数学学習サイトを、1タスク約15分のTDDループで縦切りMVPから公開まで進める計画です。

全52タスク 8 Phases 1タスク 約15分 作成日 2026-10-12

0概要

最初の完成単位: アカウントなしで、ホーム → 線形代数 → 線形写像の記事へ進み、座学・コード・p5.js可視化・4択問題まで体験できる縦切りMVP。

詳細なTDD手順と同じ計画は DEVLOG.md に記録する。HTMLは進捗確認・共有用、Markdownは実装時の手順確認用として併用する。

1ゴール / スコープ

最小の完成形

  • 登録なしでホームと教材へアクセス
  • 線形代数の記事一覧から線形写像を選択
  • 座学・コード・p5.js・4択を1記事で体験
  • スマートフォンで主要操作を完了
  • 記事ごとの自己完結フォルダを維持

今回の非ゴール

  • アカウント、クラウド進捗同期、CMS
  • 全12科目の記事制作
  • 動画撮影・編集・投稿
  • 汎用ブロックエディタ
  • Firestore / Functionsの新規機能
責務境界: Vue/Viteはトップ・科目一覧・共通導線を担当し、教材本体は public/articles/<subject>/<slug>/ の自己完結フォルダとして配信する。

2前提とリスク

  • 現在の src/ はVue/Firebaseスターター画面で、README記載の学習体験は未実装。
  • sample/ の線形写像教材を最初の縦切りMVPとして使う。原本は公開配置が安定するまで保持する。
  • キャラクターは一旦 public/fermiquest/01_Feru.png を使い、後からメタデータで差し替え可能にする。
  • YouTube URLとGitHub URLは未確定。値がない場合は空リンクを表示しない。
  • Firebase設定はプレースホルダーのため、Phase 0完了前に機能開発やデプロイを始めない。
  • MathJax/p5.js CDNは通信に依存する。MVPで検証し、必要時だけローカル配布へ切り替える。
  • 日本語をMVP対象にし、既存i18n基盤は壊さない。英語教材は後続計画に分ける。

11検証戦略

  1. 各Taskで対象テストを赤→緑にし、整理後に同じテストを再実行する。
  2. Phase終端で関連テスト群をまとめて実行する。
  3. Phase 4以降は360px、768px、1280px相当で表示確認する。
  4. Phase 7で npm test、npm run lint、npm run build を通す。
  5. ローカル成功、Hostingデプロイ成功、公開URL上の操作成功を別々に記録する。
  6. 実機タッチ・読み上げ・動画再生は、実施したものだけを確認済みにする。

12ロールバック / フォローアップ

  • 各Phaseを独立した小さなコミット候補にし、問題時は直前Phaseへ戻せるようにする。
  • sample/ と既存キャラクター画像は、公開配置が安定するまで削除・改名しない。
  • 認証・Firestore・Functionsは削除せず、MVPの画面導線からだけ外す。
  • 次の記事は同じフォルダ契約と資産テストを使って追加する。
  • 4択で学習効果を確認後、ブロック式問題の汎用設計を別計画に分ける。
